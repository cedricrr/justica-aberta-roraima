Justiça Aberta Roraima é um projeto independente, sem vínculo com o Tribunal de Justiça de Roraima ou com o Conselho Nacional de Justiça. Os números vêm da API Pública do DataJud (CNJ) e mostram só metadados de processos sem sigilo; não substituem a consulta oficial.
